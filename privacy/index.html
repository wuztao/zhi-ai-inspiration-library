Privacy Policy

Effective date: October 19, 2026 · Last updated: October 19, 2026

Current status: zhi AI Inspiration Library is an independent project in development, maintained by the GitHub account wuztao (“we”). This website is informational only. Pinterest OAuth, API access, MCP tools, AI analysis, and a personal inspiration database are not operational on this website.

1. Scope

This policy describes this public website and communications sent to its maintainer through GitHub. The planned features described below are design intentions, not claims about an existing service. This website is not affiliated with, endorsed by, or operated by Pinterest.

2. Information processed today

Visiting the website. The site consists of static HTML and CSS. It has no account registration, login, uploads, contact form, analytics scripts, advertising trackers, application cookies, or browser storage. It does not request Pinterest data or connect visitors to an AI provider. Fonts and decorative artwork are provided within the pages without third-party image or font requests.

Hosting. GitHub Pages delivers the website. GitHub states that visitors' IP addresses are logged and stored for security purposes. GitHub may process additional technical request information under its own policies. This hosting activity is separate from any project application database. See GitHub Pages data collection and the GitHub Privacy Statement.

Communications. If you contact us through GitHub Issues, we can see your GitHub username and the information you submit. We use it to respond to the request and maintain the project. Issues and replies are public, are hosted by GitHub, and may remain visible in copies or history. Do not submit passwords, access tokens, private boards, personal documents, or other sensitive information.

3. Planned Pinterest access

If a Pinterest integration is developed, it would use the official authorization flow and approved API access. It would request only permissions needed for an approved feature, initially focused on read access to the authorized user's own boards and saved Pins. We would not ask for a Pinterest password. Secret-board access, access to other users' data, and write or delete actions are not included in the proposed initial scope.

Depending on approved permissions and endpoints, a future feature might access account identifiers, board and Pin identifiers, board names, Pin titles and descriptions, source links, and image references. OAuth access or refresh tokens might be needed to maintain that authorized connection. None of this information is collected through the current website.

We do not assume that Pinterest API content may be copied into a permanent library. Pinterest's current developer guidelines restrict storage and third-party sharing of API data. Any implementation would be limited to permitted uses, with additional authorization obtained where required. This project does not offer scraping, unrestricted Pinterest search, or bulk archiving.

4. Planned AI and MCP processing

No AI provider receives visitors' information or Pinterest content from this website. No MCP server is deployed as part of this website.

AI-assisted exploration and Model Context Protocol (MCP) tools are under consideration. Before enabling a feature that shares any data with an AI service or assistant, we would identify the provider and data involved, explain its purpose and relevant retention, training and international processing practices, and obtain any required user authorization. We would also establish that Pinterest's rules and any required platform permissions permit the processing. User consent alone does not override platform restrictions or content rights.

Pinterest data would not be used to train, fine-tune, or improve AI models without Pinterest's express permission and any other necessary rights and authorizations. No provider, storage location, security implementation, or retention configuration has been selected or promised for a future service. A future MCP connection would require access controls and a defined scope; it would not itself grant unrestricted access to an account.

5. Sharing and purposes

We do not sell personal information or use this website for targeted advertising. The current site sends no Pinterest data to third parties. GitHub processes hosting requests and GitHub communications under its own policies. Clicking an external link takes you to a separate service whose privacy practices apply there.

We use voluntary communications only to handle requests and maintain the project. Information may also need to be handled to comply with applicable legal obligations. Any additional service providers or purposes would be described before a future feature begins collecting data.

6. Retention and security

There is no project-side user account database, stored Pinterest content, or OAuth token store on this website. GitHub controls retention of its hosting logs and platform records. Public issue content may remain available as part of project history; deleting an issue or comment cannot guarantee removal of third-party copies.

We will review requests to remove information from project content we control, subject to applicable obligations and the platform's capabilities. We do not claim to control GitHub's own logs, caches, or backups.

Before any authenticated feature is launched, its credential storage, access controls, retention periods, and deletion process must be implemented and described. Credentials must not be placed in public repositories or static webpages. No system can guarantee absolute security.

7. Your choices and requests

You may browse without creating an account with this project. For questions, corrections, or requests concerning information in project content, use the project's GitHub Issues page. Submit only a minimal, non-sensitive request. If a request requires personal information, ask for a private contact method before providing details. No dedicated private support channel is offered on this website today; one must be established before operating a service that collects account data.

For GitHub-held data, consult GitHub's privacy information and request channels. Depending on your location, applicable law may provide access, correction, deletion, restriction, objection, portability, withdrawal-of-consent, or complaint rights.

If a future Pinterest connection becomes available, users would be able to revoke it through Pinterest's account controls. Revoking access and deleting previously retained data are separate actions; the applicable deletion process would be published before that feature launches.

8. Children and international processing

The proposed application is not intended for children under 13. The current website does not solicit children's personal information. Please raise concerns through the contact route above without publicly identifying a child.

GitHub operates internationally, and its processing locations and safeguards are described in its Privacy Statement. No processing location is promised for a future application or AI provider; those details must be disclosed before use.

9. Policy updates

We will update this page and its date when practices change. Before enabling Pinterest, AI, MCP, or other data-processing features, we will publish a policy reflecting the actual implementation and provide any notice and consent process required for the change. Describing a planned feature here does not authorize its operation.
